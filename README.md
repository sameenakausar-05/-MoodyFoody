# 🍴 MoodyFoody

MoodyFoody is a premium food ordering web application developed using **Java, JSP, Servlets, JDBC, MySQL, HTML, and CSS** following the **MVC (Model-View-Controller)** architecture.

The application allows users to browse restaurants, explore menus, add items to the cart, place orders, and manage their profiles through a clean and modern user interface.

# 🏗 Project Architecture

The project follows the **MVC (Model-View-Controller)** architecture.

```
User
   │
   ▼
Browser
   │
   ▼
JSP (View)
   │
   ▼
Servlet (Controller)
   │
   ▼
DAO Layer
   │
   ▼
MySQL Database
```

# ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/MoodyFoody.git
```

---

### Import Project

Import the project into **Eclipse IDE**.

---

### Configure Database

Create a MySQL database.

Import the provided SQL file.

Update your JDBC configuration.

---

### Run

Deploy using **Apache Tomcat**.

Open

```
http://localhost:8080/MoodyFoody/
```
